# MediTrust Clinic (Flask + SQLAlchemy + SQLite)
1. Install: `pip install -r requirements.txt`
2. Run: `python app.py`  (database `instance/meditrust.db` and demo data are created automatically on first run)
3. Open http://127.0.0.1:5000

Demo logins (choose matching role on login page):
- Patient: patient1 / patient123
- Doctor: doctor1 / doctor123 (Dr. Smith; doctor2-5 also use doctor123)
- Admin: admin / admin123

Files: app.py (models + routes), templates/, static/style.css, static/main.js
